Block theme for Zernyar, a demo coffee roastery store on WooCommerce.

== Description ==

A block theme built around WooCommerce blocks: Product Collection for the catalog and the home page, the new Product Filters, the blockified product page, Cart and Checkout. Colours, type and spacing live in theme.json; theme.css holds the rest.

The strings are in English and translated to Ukrainian in languages/uk.po.
